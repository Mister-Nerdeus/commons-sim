# Governance

## Mission
Increase transparency and outcomes for shared-service residential systems.

## Principles
1) Determinism is mandatory.
2) Assumptions must be explicit and versioned.
3) Outputs must be explainable (no hidden black boxes).
4) Safety and regulatory reality are respected.

## How decisions are made
- Minor changes: PR + review
- Major model changes: PR + updated docs + snapshot update + maintainer approval
