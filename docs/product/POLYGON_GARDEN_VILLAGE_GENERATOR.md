# Polygon Garden Village Generator

`generatePolygonVillage` is a deterministic generator in `packages/engine/src/generators/polygonVillageGenerator.ts`.

It supports:

- `dodecagon-pod`
- `polygon-garden-village-24gon`

The generator uses explicit input and seed values, does not call external AI, does not use `Math.random`, and returns an editable ProjectManifestV2 with warnings that the result is a draft. It does not claim professional validity, build approval, or full graph compilation.
