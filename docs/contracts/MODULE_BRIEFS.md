# Module Briefs

Problem and solution briefs keep modules problem-first.

Problem briefs include:

- `problemStatement`
- `stakeholders`
- `targetScope`
- `objectives`
- `constraints`
- `stressors`
- `failureConsequences`
- `successMetrics`

Solution briefs include:

- `architectureSummary`
- `requiredInputs`
- `outputs`
- `dependencies`
- `controlStrategy`
- `technologyMaturity`
- `footprint`
- `staffingAssumptions`
- `costAssumptions`

Example:

- `examples/modules/community-meals/problem-brief.json`
- `examples/modules/community-meals/solution-brief.generic.json`
