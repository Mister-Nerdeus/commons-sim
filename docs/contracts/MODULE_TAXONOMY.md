# Module Taxonomy

Modules are problem-first contracts, not visual assets or executable runtime units.

Exports:

- `ModuleRoleSchema`
- `ModuleLifecycleStageSchema`
- `ModuleTaxonomyPathSchema`
- `ModuleIdentitySchema`

Roles include `Source`, `Sink`, `Store`, `Transform`, `Route`, `Control`, `Sense`, `Protect`, `Coordinate`, and `Demand`.

Lifecycle stages are:

- `Class`
- `Generic Template`
- `Real-World Binding`
- `Scenario Instance`

Phase B defines identity and classification only. It does not create module execution.
