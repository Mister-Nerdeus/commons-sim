# LayoutGraph

LayoutGraph stores static spatial design information for polygon communities, zones, lots, paths, service roads, utility corridors, green spaces, water features, hubs, and annotations.

It is creative design storage, not simulation truth. Geometry validation is deterministic and schema-driven. Dream Mode layouts may remain incomplete and saveable.

Non-claims:

- No renderer is implemented in the shared contract.
- No AI generation is implemented here.
- No graph compiler is implemented here.
- No engine behavior changes here.
