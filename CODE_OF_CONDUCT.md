# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our pledge
We pledge to make participation in our community a harassment-free experience for everyone.

## Our standards
Positive behavior:
- Be respectful and considerate
- Welcome constructive feedback
- Focus on evidence, units, and reproducibility
- Document assumptions and uncertainty

Unacceptable behavior:
- Harassment, discrimination, or personal attacks
- Publishing private information without permission
- Trolling, intimidation, or inciting conflict

## Enforcement
Report issues via GitHub Security Advisories or the contact listed in `SECURITY.md`.
