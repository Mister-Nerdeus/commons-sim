# Security Policy

## Reporting
If you discover a security issue, please report it privately using GitHub Security Advisories.

## Supported Runtime
- Node `20.x` only (pinned in `.nvmrc` and CI).
- pnpm `9.x` only.

## Repository Protections
- Changes to `main` must go through pull request review.
- Required checks are documented in `docs/program/BRANCH_GOVERNANCE.md`.
- Dependency review is required on pull requests.

## Scope note
This simulator is an estimation tool. Do not use it as the sole basis for construction, permitting, or life-safety decisions.
